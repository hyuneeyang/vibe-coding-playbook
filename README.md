# Vibe Coding Playbook

 

실제 프로젝트에서 반복 활용하기 위한 개인용 Vibe Coding Workflow & Toolkit

 

## Workflow

 

Idea

→ PRD

→ Design

→ Architecture

→ Plan

→ Build

→ Test

→ Review

→ Deploy

→ Iterate

 

## Vibe Coding Process

 

| Step | Process | What to do | Tools | Skills / Extensions |

|---|---|---|---|---|

| 01 | Idea | 아이디어 구체화 | ChatGPT | Ideation |

| 02 | PRD | 요구사항 정의 | ChatGPT | PRD |

| 03 | Design | UI/UX 설계 | Figma / v0 | Figma MCP |

| 04 | Architecture | 기술 구조 설계 | ChatGPT / Codex | Architecture |

| 05 | Plan | Task 분해 | Codex | Planning |

| 06 | Build | 기능 구현 | Codex / Cursor | Coding |

| 07 | Test | 기능 검증 | Playwright | Testing |

| 08 | Review | 코드 검토 | Codex | Code Review |

| 09 | Deploy | 배포 | GitHub / Vercel / Azure | Deploy |

| 10 | Iterate | 지속 개선 | GitHub Issues | Agent Workflow |
